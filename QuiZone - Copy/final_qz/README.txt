# QuiZone updated project

This is the updated QuiZone project with the image logo positioned on the left side of every page.

## Setup
1. Extract this folder.
2. Copy your existing `.env` file from your original project into this folder. It contains your MongoDB connection string and was intentionally not included in this ZIP for security.
3. Open this folder in VS Code.
4. Run `npm install` in the terminal if `node_modules` is not present.
5. Run `node server.js`.
6. Open `http://localhost:5000`.

The existing application JavaScript, models, and backend routes have been retained. The changes focus on consistent branding, headers, page titles, and correcting malformed HTML in the quiz/auth pages.
