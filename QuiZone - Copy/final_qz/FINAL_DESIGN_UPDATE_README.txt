QUIZONE — FINAL APP-STYLE DESIGN UPDATE

This package refreshes the visual design across the existing QuiZone project:
- Homepage hero, feature cards, category cards, CTA and footer
- Shared navigation and buttons
- Login and registration screens
- Quiz listing, quiz creation and quiz-taking screens
- Progress dashboard, cards, chart container and history table
- Responsive layouts for mobile and tablet

The update is CSS-focused. Existing JavaScript, Express routes, MongoDB models,
quiz submission, authentication and progress-saving logic are preserved.

SETUP
1. Extract this folder.
2. Copy your existing .env file into this project root (same folder as server.js).
   The .env file is intentionally not included in this ZIP for security.
3. Open a terminal in this folder and run: npm install
4. Start the app: node server.js
5. Visit: http://localhost:5000
6. Hard refresh with Ctrl + Shift + R.

Do not replace your .env with a blank file. Keep your existing MONGO_URI locally.
